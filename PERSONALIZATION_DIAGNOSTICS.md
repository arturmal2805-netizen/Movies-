# Проверка персонализации

Подбор использует всю историю оценок. Сравнения по общему жанру без совпадения тем, конкретного поджанра или режиссёра больше не считаются близкими соседями. Устойчивые отказы не должны автоматически обнулять интерес ко всем ужасам: веса отдельных признаков сравниваются с личным средним сигналом. «Норм» 5/5 даёт нейтральный сигнал. Кандидаты с отрицательным персональным баллом ниже -0.8 при истории от 20 оценок не отправляются ради заполнения лимита. Этот порог пока является инженерным правилом, а не результатом подгонки по закрытым оценкам пользователя.

Дополнительно запрашиваются TMDB Recommendations для максимум шести положительно оценённых фильмов. Далее кандидаты проходят общую проверку и персональное ранжирование. Анимация, документальные фильмы, китайские языки zh/cn/yue и производство CN/HK/TW исключаются независимо от поджанра, включая совместное производство. Возрастные и смешанные жанровые правила сохранены. Архив и оценки не удаляются. Неизвестная страна не подменяется догадкой по названию; старые метаданные дозаполняются с лимитом 80 фильмов на запуск.

## Реальные оценки

Нельзя утверждать улучшение на 525 личных оценках по результатам искусственных тестов. Нужен авторизованный экспорт из Supabase либо SUPABASE_SERVICE_ROLE_KEY в секретах среды. Ключ не помещается в код, отчёт или чат.

Локальный экспорт одного пользователя:

```sh
python3 scripts/diagnose_taste.py --input /tmp/my-ratings.json --output /tmp/my-taste-report.json
```

Чтение напрямую с доступом из секретов среды:

```sh
python3 scripts/diagnose_taste.py --user-id USER_UUID --output /tmp/my-taste-report.json
```

Скрипт ничего не записывает в Supabase. Проверяет все страницы оценок, полноту метаданных, распределение впечатлений и признаки с минимум тремя наблюдениями. Затем сравнивает прежнее и новое ранжирование на поздних 20% решающих оценок, обучаясь только на предыдущих 80%. Если в проверочной части нет обеих групп like/dislike, AUC остаётся null. Точность на оценённых фильмах не равна успешности будущих рекомендаций. Экспорты и отчёты следует хранить вне публичного репозитория. Их нельзя смешивать между аккаунтами.

Проверки: `npm test` и `python3 -m unittest discover -s scripts -p 'test_*.py'`. Тест с 525 искусственными оценками проверяет сохранение давнего положительного примера после массовых отказов, а не моделирует реальные предпочтения пользователя.
