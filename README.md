# ARTUR логістик

Трекер замовлень: країна відправника → забір → перевезення → склад у Польщі → митниця → розмитнення → Київ.

Кнопка «+» відкриває назву папки, далі — параметри виробника, країни, перевізника, адрес, дати доставки, ваги, номера відстеження, контакту та приміток. Папки перетягуються між етапами; на телефоні й з клавіатури етап можна змінити списком. Зміни етапів зберігаються в історії папки. Є редагування, видалення, пошук, фільтр країн, експорт та імпорт JSON.

Дані зберігаються лише в localStorage цього браузера, без сервера та синхронізації між пристроями. Очищення даних браузера видаляє замовлення: регулярно користуйтеся експортом. Не зберігайте чутливі дані у спільному профілі браузера.

Supabase та колишні API фільмів не використовуються. Старі файли та розклади Movies видалені з актуального дерева, попередня версія зберігається в історії Git. Секрети GitHub і прив’язки середовища керуються окремо в їхніх налаштуваннях; код їх не читає.

Запуск: `npm start`. Перевірки: `npm test`.
Публікація на GitHub Pages — workflow «Publish ARTUR logistics». Артефакт містить лише index.html, style.css, app.js, model.js, icon.svg та .nojekyll.
