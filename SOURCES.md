# Источники и правило карточек

Карточка должна содержать реальный постер, IMDb / 10, Popcornmeter / 100 и popularity score с названием источника и датой обновления. Пропуски отображаются как «—»; вручную записанные IMDb помечены звёздочкой. Режим «Только полные карточки» исключает записи без любого из этих полей. Существующие карточки остаются доступными при отключённых источниках. Статусы доступны через небольшую кнопку «Источники» в шапке.

## Текущее состояние

Исходная подборка — локальный массив `app.js`. На момент реализации внешние API не подключены, API-ключей в среде нет. Netflix и Shudder не импортируются. Ручные оценки не подтверждены свежим запросом. Постеры до импорта не заменяются вымышленными фотографиями.

## Автоматическое обновление

В GitHub: Settings → Secrets and variables → Actions → New repository secret.

- `TMDB_ACCESS_TOKEN`: API Read Access Token TMDB для постеров и TMDB popularity (не процент и не оценка качества).
- `OMDB_API_KEY`: ключ OMDb для обновления IMDb по точному IMDb ID. Первому импорту OMDb нужны IMDb ID, которые импортируются через TMDB.

Не вставляйте ключи в код, браузер или чат. Ключи использует только GitHub Actions. Разрешите GitHub Actions запись в репозиторий; workflow также требует Pages и OIDC permissions.

Actions → Refresh movie sources → Run workflow запускает первую проверку. По расписанию обновление выполняется каждый час на 17-й минуте. GitHub может задерживать расписание и отключает расписания неактивных публичных репозиториев; это не круглосуточный SLA. Workflow явно разворачивает Pages: коммит от GITHUB_TOKEN сам по себе не запускает обычную сборку Pages.

Импорт атомарно сохраняет `data/catalog.json`, не удаляет последние успешные значения при сбое и не выводит ключи или URL с ключами в журналы. Сайт перечитывает снимок каждые 5 минут. Старше 3 часов — статус «Данные устарели». Статус успеха отражает последний импорт, а не живую проверку провайдера в браузере.

Popcornmeter не подключён: требуется доступ к источнику зрительских оценок Rotten Tomatoes. Значение Rotten Tomatoes из OMDb нельзя автоматически считать Popcornmeter. После получения легального источника нужен отдельный адаптер. Netflix/Shudder — платформы просмотра, а не подключённые API рейтингов; доступность фильмов по странам пока не импортируется.

## Проверки

`npm test` и `python3 -m unittest discover -s scripts -p 'test_*.py'`. Проверены отсутствие ключей, сохранение данных при таймауте, обновление по точному ID и запрет подмены Popcornmeter оценкой критиков. Живой импорт без секретов не проверен. В облачной среде доступ к image.tmdb.org отклонён прокси с 403; GitHub Actions имеет отдельную сеть.
