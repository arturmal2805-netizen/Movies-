# Подбор и категории

Подбор выполняет код, без LLM и платных запросов к нейросети. Оценки и личная коллекция остаются в Supabase. Публичный снимок содержит только метаданные источников.

За запуск TMDB проверяет популярные фильмы, фильмы с высоким рейтингом, до трёх любимых жанров по отдельности и до двух любимых тем по TMDB keyword ID. Первая страница сохраняет свежие результаты; остальные страницы чередуются в диапазоне 2–20 каждый час. Максимум 24 запроса поиска. Trakt и публичная лента SIMKL дают до 60 кандидатов каждый. Это кандидаты на проверку, а не гарантированное количество добавлений.

До дорогих запросов отсекаются уже оценённые и собранные фильмы. Повторные TMDB запросы переиспользуются в пределах одного запуска, включая совпадения между источниками и пользователями. Одновременно выполняется не более четырёх запросов в одной стадии. Детальные сведения запрашиваются для ограниченного списка (до 180), затем рейтинг пересчитывается по жанрам, поджанрам, ключевым темам и режиссёрам. Ненадёжные оценки с небольшим количеством голосов сглаживаются. Небольшой штраф за повторяющиеся жанры делает одну порцию разнообразнее.

Базовая цель — 15 фильмов, дополнительные источники могут увеличить её. Для автоматических запусков жёсткий максимум — 100 добавлений за скользящие 60 минут. Ручной «Подобрать фильм +» обходит почасовые ограничения и допускает до 100 фильмов за запрос, сохраняя проверку качества и дедупликацию; он не сдвигает расписание. Настройка: [MANUAL_RECOMMENDATIONS_SETUP.md](MANUAL_RECOMMENDATIONS_SETUP.md). Найденные 1–14 подходящих фильмов тоже сохраняются. Будущие релизы, adult, карточки без постера/длительности и фильмы с менее чем 100 голосами исключаются. Сбой метаданных всей порции не отмечает час успешно завершённым, поэтому повторный запуск возможен.

Старые карточки обновляются постепенно: до 12 разных фильмов за запуск, сначала оценённые. Меняются только технические сведения внутри metadata; пользовательские оценки, saved, reason и created_at сохраняются. Новые карточки содержат featureVersion=2.

Категории используют один источник правил: config/category-rules.json. После изменения правил выполнить python3 scripts/build_category_rules.py; categories.test.js проверяет соответствие браузерного модуля серверным правилам. Точные TMDB keywords и жанры имеют приоритет. Описание используется только для явных названий поджанров; неопределённые карточки остаются в «Все фильмы». Контрольные примеры находятся в config/category-checks.json и проверяются в обоих языках. Эти примеры — регрессионная проверка, не измерение точности на всем кинокаталоге.

Проверки: npm test; python3 -m unittest discover -s scripts -p 'test_*.py'. Секреты для живого подбора доступны в GitHub Actions; локальные тесты используют подставные ответы API.
